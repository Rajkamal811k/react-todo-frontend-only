# Sylvan • Aesthetic & Natural To-Do App 🌿

A mindful, nature-inspired task and intention tracker built with React and Vite.

## ✨ Highlights & Aesthetic Design

- **Natural Organic Theme**: Earthy color palettes (*Morning Mist*, *Sunset Dune*, and *Midnight Moss*) with soft linen glassmorphism, ambient gradients, and editorial serif & sans typography (`Fraunces` + `Plus Jakarta Sans`).
- **Harmonic Audio Synthesis**: Built-in Tibetan crystal chimes and soft bamboo taps synthesized using the Web Audio API (zero external assets, instant response, with mute toggle).
- **Botanical Checkboxes**: Circular leaf checkmarks with smooth blooming animations.
- **Daily Cultivation Progress**: Planted vs. Blossomed progress meter with leaf markers.
- **Mindful Respite (Breathe Modal)**: Guided 4-4-4 breathing circle with expanding organic rhythm for centering before tasks.
- **Botanical Confetti**: Gentle organic color bursts (sage, terracotta, gold, cream petals) on task completion.
- **Realm & Energy Filters**: Filter by realms (*Mindful*, *Deep Work*, *Living*, *Wellness*, *Creative*) and energy levels (*Sprout*, *Fern*, *Bloom*).
- **LocalStorage Persistence**: Auto-saves all intentions, themes, and states.

## 🚀 Getting Started

```bash
cd my-project
npm install
npm run dev
```

The application will run locally at `http://localhost:5173` (or `http://localhost:5174`).
